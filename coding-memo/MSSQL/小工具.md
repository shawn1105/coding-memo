- ### 產生大數量的模擬資料
```
WITH Tally(N) AS (
    -- 利用三個系統表交叉相乘，瞬間產生千萬級以上的數字序列
    SELECT TOP (5000) ROW_NUMBER() OVER (ORDER BY (SELECT NULL))
    FROM sys.all_objects a 
    CROSS JOIN sys.all_objects b 
    CROSS JOIN sys.all_objects c
)
INSERT [TBL_AD_SERVER_USER] ([U_ACCOUNT], [U_AD_SERVER_IP], [U_DNS_DOMAIN]) 
SELECT 
    N'SUPPORT_388945a0', N'192.168.10.1', CAST(N AS VARCHAR(50)), 1
FROM Tally;
```
#### *CAST(N AS VARCHAR(50))為不重複的欄位*

- ### 快速查詢報表的筆數(同樣適合大量資料的查詢)
```
SELECT 
    t.name AS [資料表名稱],
    p.rows AS [總筆數]
FROM sys.tables t
INNER JOIN sys.partitions p ON t.object_id = p.object_id
WHERE t.name = '[報表名稱]'
  AND p.index_id IN (0, 1); -- 0 代表 Heap 表，1 代表有聚集索引的表
```

- ### 查詢是否有卡住的程序正在執行
```
SELECT 
    request_session_id AS [卡住的SPID],
    DB_NAME(resource_database_id) AS [資料庫],
    resource_type AS [鎖定類型],
    request_mode AS [鎖定模式]
FROM sys.dm_tran_locks
WHERE resource_associated_entity_id = OBJECT_ID([資料表]);

```
